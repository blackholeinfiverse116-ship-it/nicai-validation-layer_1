Expected Questions (Prepare These Answers)
Question	Suggested Answer
Why FastAPI?	FastAPI provides high performance, automatic OpenAPI documentation, and a clean framework for building deterministic APIs.
Why deterministic instead of ML?	The system is designed to produce reproducible, explainable intelligence suitable for operational workflows and validation.
Why JSONL logging?	JSONL supports efficient append-only logging and simplifies replay reconstruction.
Why replay?	Replay enables historical execution analysis, debugging, and validation without affecting live runtime behavior.
Why trace IDs?	Trace IDs provide end-to-end correlation across validation, intelligence generation, action routing, logging, and replay.
How do you debug runtime issues?	Start with the runtime logs, reproduce the issue, verify API behavior, inspect trace IDs, and use the replay engine to reconstruct the execution.
How do you deploy the application?	Install dependencies, run the FastAPI backend locally with Uvicorn or deploy to Render, then verify the frontend on Vercel, APIs, dashboard, and runtime behavior.
Can the system be extended?	Yes. The modular architecture allows new datasets, adapters, monitoring, authentication, and analytics to be added without changing the core runtime flow.
